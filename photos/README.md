# Свои фотографии вместо рисунков-заглушек

Кладёте файл в нужную папку — фото появляется на сайте и в приложении **сразу** (обновите страницу).
Ничего пересобирать и перезапускать не нужно, код трогать не нужно.

| Что заменить | Куда положить | Пример |
|---|---|---|
| Фото места (карточки в каталоге, «Популярное», «Пять причин», веер на главной, карусель на первом экране, страница места, «Рядом», избранное, маршруты, приложение) | `photos/places/<имя-места>.jpg` | `photos/places/donbass-opera.jpg` |
| Второе, третье фото места | `photos/places/<имя-места>_2.jpg`, `_3.jpg` … | `photos/places/donbass-opera_2.jpg` |
| …или сразу пачка фото места | папка `photos/places/<имя-места>/` с любыми именами файлов | `photos/places/donbass-opera/zal.jpg` |
| Обложка события в афише | `photos/events/<имя-события>.jpg` | если нет — берётся фото места проведения |
| Карточки «Чем заняться» на главной | `photos/directions/<направление>.jpg` | `tourism.jpg`, `creative.jpg`, `industry.jpg`, `investment.jpg`, `maritime.jpg` |
| Фон первого экрана главной | `photos/hero.jpg` | |
| Фото под заголовком раздела | `photos/pages/<раздел>.jpg` | `catalog`, `map`, `events`, `routes`, `creative`, `heritage`, `investors`, `careers`, `favorites`, `promo`, `passport`, `info`, `more` |

**Точное имя файла для каждого места, события и направления — в файле [`СПИСОК-ИМЁН.md`](СПИСОК-ИМЁН.md).**
Он создаётся заново при каждом запуске сервера; в колонке «Сейчас» видно, где ещё стоит рисунок-заглушка.

## Советы
- Форматы: `.jpg`, `.jpeg`, `.png`, `.webp`. Имя — латиницей, как в списке (регистр не важен).
- Размер: для карточек достаточно 1200 px по длинной стороне, для `hero.jpg` и разделов — 1920–2400 px. Файл до 1 МБ — сайт быстрее грузится.
- Горизонтальные фото смотрятся лучше; важное — по центру кадра (края обрезаются под форму карточки).
- Своё фото показывается **первым**, демо-фото места (если было) уходит на второе место.
- Удалили файл — снова показывается рисунок или демо-фото.
- Фото, которые владелец бизнеса загружает в личном кабинете, работают как раньше и складываются в `backend/media/`.

## Другие способы
- **Встроенные демо-фото** лежат в `web/public/img/` и прописаны у мест в `backend/app/seed.py` (поле `photos=[...]`).
  Это для «вшитых» картинок; после изменения нужно `cd web && npx vite build` и поднять `SEED_VERSION` в `seed.py`.
- **Фон главной по умолчанию** — `web/public/img/hero-main.jpg`; фото разделов по умолчанию — список `PAGE_PHOTO` в `web/src/App.tsx`.
- Папку можно перенести: переменная окружения `PHOTOS_DIR=/путь/к/папке`.
