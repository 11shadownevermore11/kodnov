# Соответствие техническому заданию

Обозначения: **С** — сайт (`web/`), **П** — приложение (`mobile/`), **API** — бэкенд (`backend/`).

## 2. Ядро и вертикали

| Требование | Реализация |
|---|---|
| Единое ядро: карта, каталог, поиск, отзывы, избранное, маршруты, события, роли, панель | Общее API `backend/app/routers/*`, одни данные для С и П |
| Вертикали настраиваются в админке: типы объектов, поля, фильтры, слой карты, формы заявок | Панель → «Вертикали и поля»: `Vertical` (цвет, иконка, слой, этап, проф. раздел, форма заявки), `Category.fields` (конструктор полей с флагом «фильтр в каталоге») |
| Новая вертикаль появляется без выхода новой версии | С опрашивает `/api/config` раз в минуту; П получает конфигурацию в офлайн-пакете; тест `test_admin_creates_vertical_without_release` |
| Классический туризм (этап 1) | 19 объектов: музеи, достопримечательности, парки, театры, кафе, отели |
| Креативные индустрии (этап 1, пилот) | 9 подотраслей (музыка, кино, игры и IT, книги, архитектура, реклама, мода, дизайн, кластеры); госинституции и студии |
| Промышленный и гастротуризм (этап 2) | Экскурсии с расписанием, дегустации, «Сделано в регионе», индустриальное наследие |
| Инвестиции «одно окно» (этап 2) | Площадки, резиденты, мастер подбора, единая заявка |
| Морское наследие Приазовья (этапы 2–3) | Объекты, истории, аудиогиды, вклад жителей, эксперты |
| Предприниматель добавляет своё предприятие и управляет им | С: «Кабинет бизнеса» → верификация → карточка; новые объекты уходят на модерацию |
| Промокоды партнёров со скидкой 3–5% | `PromoCode` (валидация 3–5%), страница «Промокоды», блок в карточке, QR-код, счётчик активаций; владелец задаёт промокод в кабинете |

## 3. Состав платформы и хранение

| Требование | Реализация |
|---|---|
| Мобильное приложение: карта, каталог, избранное, маршруты, офлайн | П: Kotlin + Compose, нижняя панель из 5 вкладок |
| Сайт: те же данные, адаптивный, постоянные адреса | `/place/<slug>`, `/events/<slug>`, `/routes/<slug>`, `/v/<slug>`, `/investors/sites/<slug>`; серверные мета-теги и JSON-LD, `sitemap.xml`, `robots.txt` |
| Кабинеты владельцев и инвесторов (веб) | `/cabinet` (владелец), «Инвесторам» + «Профиль → Заявки инвестора» |
| Панель для модераторов, кураторов, администраторов | `/admin` — разделы показываются по роли |
| Избранное, настройки, офлайн-карты, кэш — на устройстве | С: localStorage + Service Worker; П: Room (`favorites`, `cache`, `pending`), SharedPreferences, кэш тайлов osmdroid |
| Аккаунты, отзывы, ответы, заявки, кабинеты — на сервере | API + SQLite/PostgreSQL |

## 4.1 Основа

| Требование | Реализация |
|---|---|
| Карточка: название, описание, адрес, координаты, фото, время работы, контакты, статус, дата проверки, поля типа | `PlacePage.tsx`, `PlaceScreen.kt`; статус open/closed/temporarily_unavailable; дата проверки обновляется при правке владельцем/модератором |
| Кнопки «Построить маршрут», «В избранное», «Поделиться», «Сообщить о неточности» | С и П; маршрут — Яндекс Карты / OSM / «в мой маршрут»; неточность — очередь модератора, в П работает офлайн (очередь отправки) |
| Карта: слои по вертикалям, кластеры с числом, клик по кластеру → приближение или список, позиция, «Карта / Список» | С: `MapView.tsx` (Leaflet.markercluster); П: `OsmMap.kt` (собственная кластеризация) |
| Поиск по названию, адресу, тегам с морфологией и опечатками | API: `search.py` (Snowball + RapidFuzz + раскладка + синонимы); П: `Logic.search` офлайн |
| Фильтры: вертикаль, категория, рейтинг, «открыто сейчас», стоимость, формат посещения | + метки организаций, «Сделано в регионе», доступная среда, динамические поля типа |
| Сортировка по расстоянию, рейтингу, популярности | + по релевантности и названию |
| Отзывы: просмотр всем, 1–5 + текст + фото авторизованным, редактирование/удаление своих, ответ владельца, жалоба, модерация до 24 ч, владелец не оценивает свой объект | `routers/user.py`, таймер SLA в «Жалобах на отзывы»; тест `test_reviews_owner_cannot_rate` |
| Избранное без интернета | С: localStorage, синхронизация `POST /api/me/favorites/sync`; П: Room |
| Готовые маршруты: точки, порядок, время, паузы, длительность, разные вертикали; стартовый «Креативный Донецк» | 5 маршрутов; таймлайн «узлы и связи»; редактор маршрутов в панели |
| Афиша: фестивали, выставки, мастер-классы, дни открытых дверей; календарь и фильтры | Календарь месяца, фильтры по типу/вертикали/цене, запись, .ics |
| Креативные индустрии: страница вертикали, портфолио и услуги, метки, подтверждение прав, жалоба на нарушение авторских прав | Чекбокс прав для каждой работы (без него сохранение запрещено), очередь «Авторские права» у модератора |

## 4.2 Расширение

| Требование | Реализация |
|---|---|
| Офлайн-карты, поиск и карточки без сети, доступно гостю | П: `/api/sync/bundle` → Room, офлайн-поиск, загрузка тайлов области; С: Service Worker |
| Промышленный туризм: расписание, размер группы, безопасность, статусы допуска, запись, «Сделано в регионе» | Поля типа «Предприятия с экскурсиями», слоты `ExcursionSlot`, запись с проверкой мест и групп, «по заявке» → подтверждение владельцем |
| Инвесторам: площадки с контурами и паспортом, мастер подбора, единая заявка со статусами и куратором, «Новая жизнь площадок» | Полигоны на карте, редактор контура кликами в панели, скоринг с причинами, канбан куратора, история переписки, слайдер «было/стало» |
| Кадры и образование: стажировки, курсы, вакансии, наставники; запись на экскурсии и мастер-классы; статистика владельцам | `/careers`, слоты и события с записью, графики в кабинете |
| Персональные маршруты из избранного с оптимизацией по расстоянию | API `/api/routes/optimize`; П — полностью офлайн (`Logic.optimize`) |
| Морское наследие: истории, аудиогиды, материалы жителей с модерацией, закрытое пространство экспертов | Синтез речи (Web Speech / Android TTS), подтверждение прав, `ExpertNote` |
| Push- и гео-уведомления: радиус 100–1000 м, ≤ 3 в сутки, тихие часы, включаются пользователем | П: `GeoWorker` (WorkManager), настройки в «Ещё → Настройки» |

## 5. Роли и права

| Роль | Права |
|---|---|
| Гость | Просмотр, поиск, карта, офлайн, локальное избранное |
| Пользователь | + отзывы, синхронизация, личные маршруты, запись, заявка инвестора (инвестор — профиль пользователя) |
| Владелец | Верифицированный пользователь: карточка своего объекта, ответы на отзывы (без оценки), аналитика по своим объектам |
| Куратор «одного окна» | Только площадки и заявки инвесторов (чужие площадки — только просмотр) |
| Модератор | Контент, отзывы, маршруты, верификация; паспорта площадок — только просмотр (правки — через куратора) |
| Администратор | Пользователи, роли, вертикали, аналитика, техническая часть, журнал действий |
| Верификация владельца | Заявка → документ (ЕГРЮЛ/ЕГРИП/ИНН, проверка формата) + код по контактам из карточки → решение модератора, срок 3 рабочих дня |
| 2FA для служебных ролей | TOTP обязателен: без него вход в панель невозможен, при назначении роли — настройка при следующем входе |
